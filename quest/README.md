# Sippy Quest — やる気クエスト

ADHD フレンドリーな RPG 風タスク管理アプリ。タスクを「クエスト」に変換し、
25分の集中セッションでボスの HP を削って倒していきます。

公開 URL: `https://sippygames.github.io/quest/`

## 仕組み

- **クエスト** … CSV の各行が 1 クエストになる
- **ボス戦** … 見積が 3 セッション以上のタスクは BOSS 扱い。1 セッション完了ごとに HP が 1 減る
- **EXP / レベル** … セッション完了で +30 EXP、クエスト討伐で +50、ボス討伐で +120
- **ゲーム解禁チケット** … セッション 3 回クリアごとに 1 枚。ゲームは「我慢する対象」ではなく「正式な報酬」
- **ストリーク** … 1〜2 日サボっても「凍結」状態になるだけ。翌日 1 セッションで復活する減点なし設計
- 進捗（HP・レベル・チケット等）はブラウザの localStorage に保存される

## タスク CSV の自動登録

アプリは同じフォルダの **`tasks.csv`** を自動で読み込みます。
Claude Code にタスク管理 CSV を作ってもらっている場合は、
**このリポジトリの `quest/tasks.csv` に書き出して push するだけ**で、
ページを開く（または「tasks.csv を再読み込み」を押す）とクエストとして登録されます。

コミット不要で試したいときは、CSV ファイルをページにドラッグ＆ドロップしても読み込めます。

### CSV フォーマット

1 行目はヘッダー。列名は日本語・英語どちらでも認識されます（順不同・不要な列は省略可）。

| 列 | 認識される列名の例 | 説明 |
|---|---|---|
| タスク名（必須） | `タスク` `タスク名` `title` `task` `name` `やること` `内容` | クエスト名になる |
| 見積 | `見積` `ポモドーロ` `工数` `estimate` `sessions` `hp` | 討伐に必要なセッション数（省略時 1、3 以上で BOSS） |
| 優先度 | `優先度` `priority` | `高`/`中`/`低` または `high`/`medium`/`low` |
| 期限 | `期限` `締切` `due` `deadline` | 表示・並び順に使用 |
| 状態 | `状態` `ステータス` `status` `done` | `完了`/`done`/`済` なら討伐済みとして同期 |
| ID | `id` `番号` | あればタスクの同一性判定に使用（タイトル変更に強くなる） |

例:

```csv
タスク,見積,優先度,期限,状態
メールの返信をまとめて片付ける,1,高,2026-08-08,未着手
新作ゲームの企画書を書く,5,高,2026-08-14,未着手
```

ヘッダーが無い CSV の場合は、1 列目をタスク名として全行読み込みます。

### Claude Code への指示例

タスク管理をお願いしている Claude Code セッションには、こう伝えれば連携できます:

> タスク一覧を `quest/tasks.csv` に「タスク,見積,優先度,期限,状態」のヘッダー付きで書き出して、
> sippygames.github.io リポジトリに push してください。見積はポモドーロ数（25分単位）で。
