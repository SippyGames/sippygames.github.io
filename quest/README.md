# Sippy Quest — やる気クエスト

ADHD フレンドリーな RPG 風タスク管理アプリ。タスクを「クエスト」に変換し、
集中セッション（ポモドーロ）でボスの HP を削って倒していきます。

公開 URL: `https://sippygames.github.io/quest/`

## プライバシー設計：アプリは公開・データは端末内のみ

- アプリのページは誰でも開けますが、**タスクの中身と進捗はブラウザの localStorage にのみ保存**されます。リポジトリにもサーバーにも送信されません
- タスク CSV は「CSVファイルを選ぶ」ボタン（スマホなら OneDrive / Google ドライブ内のファイルも選択可）またはドラッグ＆ドロップで読み込みます
- 一度読み込んだ CSV は端末内に記憶され、次回から自動復元されます
- **実際のタスク CSV をこの公開リポジトリにコミットしないでください**（コミットすると内容が公開されます）

## 使い方

1. https://sippygames.github.io/quest/ を開く（スマホは「ホーム画面に追加」推奨）
2. タスク CSV を読み込む
3. クエストを選んで「たたかう！」→ 15/25/45 分の集中セッション
4. セッション完了でボスの HP が減り、EXP・レベル・チケットを獲得

## ゲームルール

- 見積 3 セッション以上のタスクは 👹BOSS 戦
- タイマーより早くタスクが終わったら **「👑 討伐完了！」** で即勝利（セッション・討伐のフル報酬）
- アプリ外ですでに終わっていたタスクは、クエストカードの **「✓済」** ボタンで討伐済みにできる（討伐 EXP のみ獲得）
- セッション完了 +30 EXP／クエスト討伐 +50／BOSS 討伐 +120
- セッション 3 回クリアごとに 🎟 ゲーム解禁チケット 1 枚（ゲームは我慢ではなく正式な報酬）
- ストリークは 1〜2 日空いても「凍結」になるだけ。翌日 1 セッションで復活。「にげる」にもペナルティなし

## タスク CSV のフォーマット

サンプル: [`tasks.sample.csv`](tasks.sample.csv)

1 行目はヘッダー。列名は日本語・英語どちらでも認識されます（順不同・不要な列は省略可）。

| 列 | 認識される列名の例 | 説明 |
|---|---|---|
| タスク名（必須） | `タスク` `タスク名` `title` `task` `name` `やること` `内容` | クエスト名になる |
| 見積 | `見積` `ポモドーロ` `工数` `estimate` `sessions` `hp` | 討伐に必要なセッション数（省略時 1、3 以上で BOSS） |
| 優先度 | `優先度` `priority` | `高`/`中`/`低` または `high`/`medium`/`low` |
| 期限 | `期限` `締切` `due` `deadline` | 表示・並び順に使用 |
| 状態 | `状態` `ステータス` `status` `done` | `完了`/`done`/`済` なら討伐済みとして同期 |
| ID | `id` `番号` | あればタスクの同一性判定に使用（タイトル変更に強くなる） |

## Claude Code との連携

タスク管理をお願いしている Claude Code セッションにはこう伝えます:

> タスク一覧を「タスク,見積,優先度,期限,状態」のヘッダー付き CSV で
> OneDrive（例: `C:\Users\<名前>\OneDrive\SippyQuest\tasks.csv`）に書き出して。
> 見積はポモドーロ数（25分単位）で。**公開リポジトリには push しないで。**

書き出された CSV をアプリに読み込めばクエスト化されます。

### 討伐結果を CSV に反映する（双方向同期）

「討伐結果を書き出す」ボタンで、**討伐済みタスクの状態列を「完了」に更新した
`tasks-done.csv` をダウンロード**できます（元 CSV の列構成は保持、状態列が無ければ追加）。

⚠️ このファイルで**元の `tasks.csv` を上書きしないでください**。書き出し内容は
「アプリが読み込んだ時点」のリストなので、その後にタスク管理側で追加された
タスクを知りません。上書きすると新規タスクが消えます。あくまで**完了報告書**として
扱い、タスク管理側の Claude Code に ID で突き合わせて完了フラグだけを
取り込んでもらいます。運用ループ:

1. タスク管理の Claude Code が `tasks.csv` を書き出す → アプリに読み込む
2. アプリでクエストを討伐する
3. 「討伐結果を書き出す」→ `tasks-done.csv` を OneDrive の SippyQuest フォルダに保存
4. タスク管理の Claude Code が完了フラグを差分マージし、`tasks.csv` を再生成する
5. 再生成された `tasks.csv` をアプリに読み込み直す

補足（タスク管理側の取り込みルール）:

- スマホから OneDrive に保存すると同名ファイルに `tasks-done 1.csv` のような
  **連番が自動で付くことがある**。取り込みは固定名ではなく
  **`tasks-done*.csv` にマッチする全ファイル**を対象にすること
- 複数ファイルがある場合は**全ファイルの完了フラグを合算**して取り込む
  （完了は増える一方なので、順不同で union して矛盾しない）
- **取り込み終えたファイルは削除する**（二重取り込みと取り違えの防止）

## （任意）共有 tasks.csv の自動読み込み

`quest/tasks.csv` をリポジトリにコミットすると、「共有tasks.csvを読み込む」ボタンで
取り込めます。ただし**公開リポジトリのため内容は誰でも見られる**点に注意。
公開しても問題ないタスクにのみ使ってください。
